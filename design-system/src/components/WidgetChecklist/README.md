# WidgetChecklist

Widget für Bereitschaft und Compliance: bis zu vier `StatusChip` mit Wert „Bereit“ in `success`, ohne Kopfzeile bündig ab Panel-Oberkante, nacheinander einblendend.

- `items`: kurze Nachweise („EU AI Act“, „Hosting in Frankfurt“).
- `value` ändert das Wort für alle Zeilen; pro Zeile über `{ label, value }`.
