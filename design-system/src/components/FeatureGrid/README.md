# FeatureGrid

Die Feature-Reihe: fünf `FeatureCard` à 264 × 386 mit `space-4` Abstand – 1384 px breit und damit bewusst breiter als `container`.

- Reihenfolge wie in Figma: vier Widget-Karten in lime, mint, turquoise, sky-blue, am Ende die indigo-CTA-Karte.
- Unter 1440 px wird die Reihe horizontal scrollbar mit Snap auf jede Karte; der Seitenrand bleibt `gutter`.
- Darüber steht ein `SectionHeader` mit `align="left"` („Das kann Madita“) und rechts ein `outline`-Button mit Pfeil.
