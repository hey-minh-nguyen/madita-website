# WidgetLanguages

Widget für Mehrsprachigkeit: Begrüßungen in DM Sans SemiBold 20 laufen endlos nach oben durch das Panel, oben und unten ausgeblendet. Jede dritte Zeile apple, jede fünfte mint, sonst weiß.

- `words`: sechs bis zehn Grußformeln in verschiedenen Sprachen, kurz genug für eine Zeile.
- `duration` in Sekunden pro Durchlauf (Standard 12). Bei `prefers-reduced-motion` steht der Ticker still.
- Für Screenreader trägt das Widget eine Beschreibung (`label`).
