# Icon

Ein Icon aus dem kuratierten Phosphor-Satz (Regular), 18 px, in der Textfarbe.

- `name`: Phosphor-Name, z. B. `shield-check`, `calendar-blank`, `arrow-right`. Alle Namen stehen in `index.d.ts` (`IconName`) und unter `Madita.Icon.names`.
- Dekorativ neben einem Wort: ohne `label` (wird `aria-hidden`). Allein stehend, z. B. als Button ohne Text: `label` setzen.
- In Buttons nicht selbst einsetzen, sondern `Button icon="…"`.
- In Boxen im schwarzen Kreis: Kreis 40 px `grey`, Icon weiß.
