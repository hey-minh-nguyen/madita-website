# Checkbox

Einwilligung unter Formularen, zeichnet sich in `currentColor` und funktioniert daher auf Weiß und auf indigo.

- Box 16 px (Figma zeichnet 10 px – für Bedienbarkeit vergrößert), Text 12 px.
- Immer mit Klartext-Label; nie vorausgewählt, wenn es um Marketing-Einwilligung geht.
- Box und Haken übernehmen die Textfarbe der Fläche: auf Weiß `ink`, auf `surface-brand`, `surface-inverse` und `surface-brand-deep` Weiß. Nie eine dunkle Box auf dunkler Fläche.
