# StatusChip

Zeile in dunklen Produkt-Kacheln: Label links, Wert rechts. 32 px hoch, `radius-sm` (im Widget-Panel `radius-xs`), Padding 0/12, Fläche grey-05 mit 10 % Deckkraft, Text `micro` (12 px).

- Nur auf `surface-inverse` (z. B. im Visual-Panel einer FeatureCard).
- `tone="success"` färbt den Wert `success` – nur hier ist grüner Text erlaubt (6,6:1 auf grey).
- Stapeln mit 4 px Abstand.
