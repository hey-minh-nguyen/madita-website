# EmailCapture

Ein-Feld-Formular aus Pill-Input und Button, immer auf `surface-brand`.

- `tone="light"`: weißes Feld – Interview-Demo („Interview starten“).
- `tone="dark"`: grey-Feld – Newsletter-Leiste im Footer.
- Eingabe in DM Sans Regular 15, wie in allen Formularen. Das Label ist visuell versteckt, aber vorhanden (`label`).
- Darunter optional eine `Checkbox` für die Einwilligung.
- Der Consumer liefert `onSubmit(email)` und Texte.
