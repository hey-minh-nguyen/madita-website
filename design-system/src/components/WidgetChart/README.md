# WidgetChart

Widget für Wachstum: Kopfzeile („Interviews pro Woche“) und fünf bis sieben Balken, die vom unteren Panelrand aufsteigen. Die letzten zwei Balken voll `indigo`, die übrigen mit 60 % Deckkraft.

- `values` frei skaliert auf die Panelhöhe; der Verlauf soll steigen.
- `highlight` = Anzahl hervorgehobener Balken (Standard 2).
- Kein Achsen- oder Zahlenwerk – das Widget zeigt eine Tendenz, keine Statistik. Echte Zahlen gehören in `Stat`.
