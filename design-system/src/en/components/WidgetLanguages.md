# WidgetLanguages

Widget for multilingualism: greetings in DM Sans SemiBold 20 scroll endlessly upwards through the panel, faded out at the top and bottom. Every third line apple, every fifth mint, the rest white.

- `words`: six to ten greetings in different languages, short enough for one line.
- `duration` in seconds per loop (default 12). With `prefers-reduced-motion` the ticker stands still.
- For screen readers the widget carries a description (`label`).
