# Field

Addition (shadcn-inspired): labelled input field for contact and demo forms. Input as a pill (42 px, `surface-subtle`), textarea with `radius-md`.

- Label always visible (13 px Bold); a placeholder never replaces a label.
- Error: red border + `error-tint` + text with an exclamation icon. The message says what to do.
- Keep required fields to a minimum; a work email is enough for the first step.
