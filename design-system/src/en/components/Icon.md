# Icon

An icon from the curated Phosphor set (Regular), 18 px, in the text colour.

- `name`: Phosphor name, e.g. `shield-check`, `calendar-blank`, `arrow-right`. All names are listed in `index.d.ts` (`IconName`) and in `Madita.Icon.names`.
- Decorative next to a word: no `label` (becomes `aria-hidden`). Standing alone, e.g. as a button without text: set a `label`.
- Don't place icons in buttons yourself, use `Button icon="…"`.
- In boxes inside a black circle: circle 40 px `grey`, icon white.
