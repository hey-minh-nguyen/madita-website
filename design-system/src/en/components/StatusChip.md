# StatusChip

A row in dark product tiles: label on the left, value on the right. 32 px high, `radius-sm` (`radius-xs` inside a widget panel), padding 0/12, surface grey-05 at 10% opacity, text `micro` (12 px).

- Only on `surface-inverse` (e.g. in the visual panel of a FeatureCard).
- `tone="success"` colours the value `success`; this is the only place green text is allowed (6.6:1 on grey).
- Stack with 4 px gaps.
