# Highlight

Lime marker (`marker`, radius `radius-marker`) behind one or two words of a headline, the signature element of the site.

- Exactly one marker per headline, never across the whole line.
- Mark the benefit word: „immer gewünscht“ / “always wanted”, „gelernt“ / “learned”, „transformieren“ / “transform”, „Madita“.
- Wraps cleanly across lines (`box-decoration-break: clone`).
- Alternative in the hero headline: an accent in `ink-brand` instead of the marker (“your AI recruiter” in indigo, class `md-accent`).
