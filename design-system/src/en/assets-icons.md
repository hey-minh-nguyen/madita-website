# Icons

Curated set from [Phosphor Icons](https://phosphoricons.com) 2.1, weight **Regular**, MIT licence. viewBox 0 0 256 256, `fill="currentColor"`, so the colour comes from the text.

Always 18 px (`icon-size`), in the bundle via `<Icon name="…" />`. All files are named as in Phosphor; add missing icons in the same weight from Phosphor.

Navigation and actions: arrow-right, arrow-left, arrow-down, arrow-up-right, caret-down, caret-right, list, x, plus, minus, magnifying-glass, link, download-simple.
Status: check, check-circle, x-circle, info, warning, star.
Media and interview: play, pause, speaker-high, speaker-slash, microphone, headset, phone, chat-circle-text, quotes, translate, globe.
Contact and scheduling: envelope-simple, calendar-blank, clock, map-pin.
Recruiting and product: users, user-circle, buildings, briefcase, handshake, trend-up, chart-bar, squares-four, plugs-connected, file-text, lightning, eye.
Trust: shield-check, lock-simple.
