# Icons

Kuratierter Satz aus [Phosphor Icons](https://phosphoricons.com) 2.1, Gewicht **Regular**, MIT-Lizenz. viewBox 0 0 256 256, `fill="currentColor"` – die Farbe kommt aus dem Text.

Größe immer 18 px (`icon-size`), im Bundle über `<Icon name="…" />`. Alle Dateien heißen wie in Phosphor; fehlende Icons im selben Gewicht aus Phosphor ergänzen.

Navigation und Aktionen: arrow-right, arrow-left, arrow-down, arrow-up-right, caret-down, caret-right, list, x, plus, minus, magnifying-glass, link, download-simple.
Status: check, check-circle, x-circle, info, warning, star.
Medien und Interview: play, pause, speaker-high, speaker-slash, microphone, headset, phone, chat-circle-text, quotes, translate, globe.
Kontakt und Termine: envelope-simple, calendar-blank, clock, map-pin.
Recruiting und Produkt: users, user-circle, buildings, briefcase, handshake, trend-up, chart-bar, squares-four, plugs-connected, file-text, lightning, eye.
Vertrauen: shield-check, lock-simple.
